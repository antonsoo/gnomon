# A 300 mm sundial on A4 or Letter

These files are actual downloads from the locally built application:

- [north-a4.pdf](north-a4.pdf): Chromium, A4, four full-size plate sheets, a guide and a gnomon sheet.
- [north-letter.pdf](north-letter.pdf): Firefox, Letter, the same six-page arrangement.

The two north files describe a horizontal circle at 45 degrees north, longitude zero,
using local apparent solar time. The radius is 150 mm. Set your own location
in the application to make a dial for use elsewhere.

Print on the named paper at Actual size / 100%, single-sided, with no further
poster tiling. Measure every calibration bar and both dimensions of each
frame before cutting. Retain the 10 mm printed overlaps, match the targets,
and tape the backs. Use the matching style template included in the PDF.
Match the filled foot dots and open base-end circles.

For a compact starting point, [garden-a4.pdf](garden-a4.pdf) contains a 90 mm
radius fan and its style on two A4 pages (same location and solar-time basis).
This compact example was generated directly from the library.
