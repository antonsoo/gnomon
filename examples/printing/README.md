# A 300 mm sundial on A4 or Letter

These files are actual downloads from the locally built application:

- [north-a4.pdf](north-a4.pdf): Chromium, A4, four full-size sheets plus a guide.
- [north-letter.pdf](north-letter.pdf): Firefox, Letter, the same arrangement.

They describe a horizontal circle at 45 degrees north, longitude zero,
using local apparent solar time. The radius is 150 mm. Set your own location
in the application to make a dial for use elsewhere.

Print on the named paper at Actual size / 100%, single-sided, with no further
poster tiling. Measure every calibration bar and both dimensions of each
frame before cutting. Retain the 10 mm printed overlaps, match the targets,
and tape the backs. The style uses the separate Gnomon SVG template.

[Instructions, measured PDF evidence and limitations](../../docs/printing.md).
The files have been checked digitally; physical printing and assembly remain
unverified. This feature has not been deployed to the hosted site.
